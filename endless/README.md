# 无尽 · ENDLESS

《无尽》是一款原创、零付费的竖屏无尽防线游戏。它只复用了既有项目的“研究 → 设计 → 实现 → 浏览器验收 → GitHub Pages 发布”流程，不复用《疆域争锋》的题材或游戏内容。

## 运行

在本目录启动静态服务器：

```powershell
python -m http.server 4173
```

然后访问 <http://localhost:4173>。

## 当前玩法

- 中央战场保持纯净：宽屏时状态、控制与炮塔阵列位于左侧，常驻 DPS/HPS、卡牌和说明位于右侧；两侧面板会按浏览器剩余横向空间自动加宽并分别限制在合理上限，窄竖屏使用左右抽屉。
- 开局只有子弹主炮；激光、导弹、冰霜、电弧和支援炮塔必须通过选牌部署，六座炮塔统一位于战场底部。
- 每次选牌固定四选一；右侧可指定六种炮塔或“特殊规则”作为卡牌偏好，弹框必定包含一张对应标签的合法未满级卡牌，其余卡位继续从合法牌池随机。每个偏好按钮会显示本局对应卡牌的累计等级。
- “弹道火控总成”将原有的全局伤害、全局攻速、子弹伤害和子弹射速合并为一张成长卡；旧存档中四张旧牌的等级会自动折算并受新卡等级上限约束。
- 卡牌包含吸血、护盾、易伤、范围减速、持续伤害、处决、连锁和多套跨流派组合。
- “禁忌洞见”可叠加到 5 级：每级提供 10% 的波末触发率，前四级触发一次追加四选一，满级触发两次；每次接受追加卡牌都会牺牲当前屏障生命的 50%。
- 限时猎物从第 3 波开始出现并随进度增至每波最多 5 个；初始基础击杀窗口为 34 秒，随后每波缩短 0.75 秒、最低 8 秒，生命和减伤也会逐步提高。延时、削减生命和破防三条特殊卡分支集齐后可合成“悬赏统御协议”，把高压悬赏转化为持续选牌循环。
- 炮塔群共用一座有耐久的浅圆弧玻璃屏障；黄色护盾先承伤，随后扣除蓝色屏障。屏障就是唯一生命线，归零立即失败；支援炮塔负责在失守前修复屏障并补充黄色护盾。
- 五种攻击炮塔都有前线子炮塔卡牌：子炮塔会部署到敌军附近并提供对应火力或控制。默认敌军不会绕路追逐，只攻击进入自身攻击范围的子炮塔；获得“引力诱捕器”后才会在有限半径内改变路线。支援后期可修复全部子炮塔。
- 每座攻击炮塔独占控制面板一行，并以四个单选项设置“最近、最远、血最多、血最少”攻击优先级；支援炮塔显示为全屏自动支援。
- 每种进攻炮塔的专属射程卡最多 3 级，依次提升到一档扩展、二档远域和三档全屏；子弹主炮基础射程固定为 700，“远射弹道”依次提升到 950、1200 和全战区覆盖。前线小型子炮塔共享对应射程卡成长，鼠标悬停显示主炮真实范围。
- 普通敌人不显示血条，而是随剩余生命缩小；首领保留血条。易伤、燃烧和减速使用独立小图标显示，燃烧数字按短时间窗口合并，不再出现大量 0。
- 敌方单位默认使用天体美术：小行星、彗星、卫星、恒星、中子星和黑洞；恒星具有日冕、耀斑与表面纹理，黑洞使用事件视界、光子环、引力透镜和吸积盘分层表现。设置中可切换回战术单位外观。
- 每一波至少生成一颗大型 Boss；每 3 波固定出现黑洞首领，在金冕、蓝白、紫极和暗红四种体积云层材质中轮换。黑洞等级随节点提高，生命与碎防压力同步成长，可见直径随等级缓慢增加但最多为战场宽度的一半，水平、俯仰和滚转角在安全区间内随机。
- 所有大型 Boss 出场后的前 5 秒处于无敌状态，完全免疫伤害、易伤、减速、冻结、眩晕和破碎，并显示护盾环与倒计时。保护结束后，Boss 仍免疫控制；黑洞额外免疫电离诱引和子炮塔嘲讽，不停火、不改道，只会缓慢推进。
- 大部分普通敌军会一边推进一边发射实体弹幕；恒星单位周期释放覆盖全体友军的辐射环，黑洞会先预警、再向屏障发射高能伽马射线。
- 第 3 波起会出现裂殖增生舰，死亡后分裂成多个高速尖晶，且敌军总量随波次上升。导弹的爆炸半径、额外齐射与蜂群分裂弹会优先处理密集敌群；“裂群清算协议”可让裂殖单位触发连锁殉爆。
- 黑洞 Boss 不会随剩余生命缩小；击破时不使用通用爆炸，而是让事件视界、吸积盘与体积云带分层雾化、拉散并烟消云散。
- 第 8 波起敌方远程单位会停下并直接攻击最终防线。
- 取消金币与军械商店；全局基础攻击力、暴击率、暴击伤害和攻击速度全部改为可叠加的随机卡牌。
- 卡牌图鉴显示所有可获得卡牌、当前等级和可合成组合。
- 战斗统计按伤害来源着色，使用最近 5 秒滚动窗口计算逐来源即时 DPS/HPS，并以 0.2 秒刷新、平滑插值连续过渡；停止攻击时保留上一时刻的非零 DPS。超过千级的面板数值和飘字统一使用 `k / m / b / t` 等紧凑单位，悬停来源条仍可查看精确整数。
- 导弹炮拥有并列发射架、蜂群分裂弹头与饱和火力协议：额外导弹优先攻击不同目标，每枚大型导弹还能分裂出不会继续递归的微型制导弹；三条分支成型后每第 4 轮齐射追加镜像弹幕。
- 电弧炮降低了基础伤害、跳跃保留伤害和过载倍率，继续以全场传播电离易伤而非直接压过其他炮塔为主要定位。
- 寒冰破碎与火焰破碎可分别由冰霜炮、导弹炮概率施加；双标记触发高额局部热震 AOE，伤害在两座炮塔之间平摊。易伤带来的额外伤害会计入施加易伤的炮塔。
- 组合牌同时归入所有参与炮塔的标签，并用对应颜色渐变显示。“低温电离桥 / 折光制导桥 / 弹巢维修桥”单独收益刻意偏低，三张全部集齐后解锁六塔共有的“六相坍缩协议”，形成随波次成长的全域质变。
- 所有带“特殊”标签的卡牌使用青、蓝、紫、玫红和金色组成的多彩毛玻璃卡面，不再与普通紫色功能牌混淆。
- 背景音乐按指定的 14 首 Melodysheep 曲目顺序循环，设置中可切换随机播放；背景音乐和战斗音效可独立开关。
- 设置面板使用带遮罩和关闭按钮的居中弹窗，支持 UI 字体缩放、选卡时是否暂停、敌军外观和音乐播放方式。

## 账号与存档

- 游玩前必须创建或登录本机账号；4 位口令仅保存 SHA-256 摘要，不保存明文。
- 不同账号的存档和最佳纪录相互隔离。
- 下次进入会默认定位到上次登录账号，并显示上次战局。
- 每次全新开局或确认重新开始都会先获得 5 轮连续四选一，然后再进入第 1 波。
- 账号记录最高已清波次。重新开局时可从 `最高已清波次 - 5` 附近快速部署：手动补发数量按“跳过波次 + 预计奖励敌人 + 基础 5 轮 + 每跳过 5 波额外 1 轮”计算；全自动随机部署在该数量上再额外获得 8 张随机合法卡牌。
- 支持手动保存、每 10 秒自动保存、波次节点保存、切后台保存和离开页面前保存；窗口失焦或切换标签页不会自动暂停战斗。
- 登录后可直接“加载存档”，也可“放弃并重开”；游戏内左侧控制台始终提供独立的载入存档按钮。
- 当前静态版本使用浏览器 `localStorage`，不会跨设备同步，也不会上传口令或战绩。
- 内置“测试账号”的口令固定为 `1111`；登录后会出现“直接测试黑洞首领”，无需推进普通波次即可轮换检查四色程序化黑洞和全炮塔基准构筑。

## 操作

- 左侧控制台：保存、载入、暂停、重新开始、背景音乐、战斗音效、设置、账号与波次状态。重新开始带二次确认，确认后清除当前战局并从第 1 波部署，但保留账号最高纪录与快速部署进度。
- 左侧炮塔阵列：每座炮塔一行，进攻炮塔直接选择四种攻击优先级；屏障与黄色护盾数值只显示在战场圆弧中央。
- 右侧控制台：常驻 DPS/HPS 分色计量表、卡牌图鉴和说明。
- 窄竖屏：点击左右边缘按钮打开对应抽屉，点击战场收起。
- `空格`：暂停或继续。

## 技术

游戏由原生 HTML、CSS、Canvas 2D 和黑洞专用 WebGL2 构成，无第三方运行依赖，无构建步骤，可以直接部署到 GitHub Pages。黑洞仍由程序化光路与云层着色器生成，不加载位图贴图；生成后的 192/224 像素动画帧会按颜色和量化姿态保存在内存中，普通设备缓存 5 帧、低核心设备缓存 4 帧，并在 Canvas 2D 中交叉淡化。缓存缺帧不会在战斗绘制路径同步重算，而是在浏览器空闲时间分批预热；黑洞在场时战场绘制上限为 48 FPS，逻辑更新保持独立。
