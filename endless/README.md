# 无尽 · ENDLESS

《无尽》是一款原创、零付费的竖屏无尽防线游戏。它只复用了既有项目的“研究 → 设计 → 实现 → 浏览器验收 → GitHub Pages 发布”流程，不复用《疆域争锋》的题材或游戏内容。

## 本轮更新（v152）

- 成就档案改为“同类别一条等级轨道”：十大难度传承、累计击杀、奖励怪、屏障里程碑与炮塔终结者均只显示当前 `LV`、最高完成条件和下一等级，不再把每一级展开成独立卡片；旧成就 ID 继续保留以兼容既有账号。
- 新增六类 50 级“炮塔终结者”：子弹炮、激光炮、导弹炮、冰霜炮、电弧炮与支援炮塔在某一难度通关时若整局归属伤害并列最高，即把对应复演核心提升到该连续难度等级（行星 I 为 LV.1，终焉奇点 V 为 LV.50）。分段屏障撞击与全局相位反冲伤害不计入支援冠军；成长路线卡成功提供成长后，复演概率由 11% 逐级提升至 60%，最多额外结算一次且从下一局生效。
- 新增十级成就“微壁垒纪元”与遗物“壁垒原核”：任一分段屏障历史生命上限依次达到 1b、10b、100b，直至 1e18 时升级；新局五段屏障初始总生命固定增加 10、100、1,000，直至 10b。该固定值在屏障晶种百分比之后相加，不会被重复放大。
- 左上控制区新增“保存并返回初始菜单”按钮；保存成功后可从部署页继续存档，失败则保留当前战局。账号每次登录会自动定位到已解锁的最高难度，新账号为行星 I，全解锁账号为终焉奇点 V；玩家回到菜单后仍可主动选择较低难度。
- 卡牌总览统一排除设计废卡，满收集时子弹炮显示 93/93、特殊卡显示 129/129、支援显示 108/108。普通账号每个基础卡只展示当前最高已拥有等级（拥有 III 时隐藏 I/II）；未拥有显示 I 级预览，设计账号仍保留全部等级用于逐级评审。旧冰霜卡 ID 与旧商店属性会统一迁移到现行卡牌、按最高等级合并，部署页卡数与实际读档保持一致。

## 上轮更新（v151）

- 左上战斗信息区新增当前难度，始终显示实际生效的大难度与威胁阶（例如“行星 I”）；读档与第 50 关 Boss 直战同样使用本局冻结难度。
- 大难度扩展为 10 个：行星、恒星、中子星、黑洞、星云、星团、星系、类星体、宇宙网、终焉奇点；每个大难度仍有 I～V 五个小阶，共 50 个连续威胁阶，相邻阶敌方战斗数值严格 ×1.5。
- 五件常规遗物统一扩展至 10 级，并固定由每个大难度的对应小阶通关升级：I 攻击范围、II 开局补给、III 基础攻击、IV 屏障生命、V 基础攻速。射程卡保留原五档数值，不因遗物系统削弱；所有新遗物等级仍从下一局生效。
- 新增“群星战勋簿”：累计小怪击杀从 1,000 起、每级需求翻倍，分裂体与召唤物均计数；每 100 个小怪进行一次固定 20% 判定，成功后令本局全局伤害永久提高遗物等级对应的 1%～10%。
- 新增“悬赏回声信标”：累计任意星级奖励怪击杀从 100 起、每级需求翻倍；每击杀 5 个奖励怪，按遗物等级获得 10%～40% 概率额外召唤一个同星级奖励怪。
- 新增 ★1 特殊卡“余辉演化”，五级概率为 10% / 13% / 16% / 20% / 25%；每波结束常规四选一确定后，可能让刚选的卡牌额外升一级。开局、奖励怪、禁忌抄本和已满级目标不触发。
- 卡牌的每一级改为独立档案：例如“弹芯增压·I”与“弹芯增压·II”分别显示固定名称和该级效果，最近获取、开局展示和图鉴不再随着后续升级改写旧卡内容。子弹炮历史目录仍是 99 级，其中 6 级废卡不计入，真实可获取上限保持 93。
- 详细伤害面板改为按卡牌系列合并，不区分该卡的等级；在“简易 / 详细”下方新增“全部 / BOSS / 小怪”目标筛选，多 Boss 波次可选择具体 Boss，并在标题中显示 Boss 名称。战斗日志升级为逐敌记录，保存每个敌人的炮塔类别、具体来源、直接/间接伤害和卡牌系列伤害；完整逐敌明细保留在当前会话并可下载，本机续局存档只保存每波聚合数据，避免后期存档超出浏览器容量。
- “相位回充”取消脱离战斗限制，战斗中持续按等级恢复护盾。账号面板始终显示所选账号的删除状态：普通账号可在未登录时凭 4 位口令删除，测试账号和设计账号明确显示为系统账号不可删除。

- 新增四级遗物“远域测距阵列”：首次以行星、恒星、中子星、黑洞难度完成第 50 波时逐级解锁；每次击杀合格普通小怪有 10% / 13% / 16% / 20% 概率，让该次击杀归属的攻击炮塔在本局永久获得 +1 射程。可识别来源归给对应炮塔，其他间接来源归给本波伤害最高的攻击炮塔，分段屏障击杀不归属；Boss、限时猎物与召唤物也不触发。成长随战局保存，本局中途解锁的遗物仍从下一局生效。

## 运行

在本目录启动静态服务器：

```powershell
python -m http.server 4173
```

然后访问 <http://localhost:4173>。

## 当前玩法

- 中央战场保持纯净：宽屏时状态、控制与炮塔阵列位于左侧，常驻 DPS/HPS、卡牌和说明位于右侧；两侧面板会按浏览器剩余横向空间自动加宽并分别限制在合理上限，窄竖屏使用左右抽屉。
- 开局只有子弹主炮；激光、导弹、冰霜、电弧和支援炮塔必须通过选牌部署，六座炮塔统一位于战场底部。
- 每次选牌固定四选一；右侧可指定六种炮塔或“特殊规则”作为卡牌偏好，弹框必定包含一张对应标签的合法未满级卡牌。刚选过的类别会按最近三次选择获得 38% / 62% / 82% 的短期权重，完全恢复后再回到正常概率；同一张卡还会额外降权，让被压低的概率自动流向其他类别。每个偏好按钮会显示本局对应卡牌的累计等级。
- 已删除“弹道火控总成”。六座炮塔分别拥有攻速、射程、基础效果、暴击率与暴击效果五张 ★1 基础卡，旧存档火力等级自动折算为子弹炮基础卡。子弹炮当前真实可获取等级上限为 93；已废弃的三张“奇点弹仓”共 6 级不会再计入构筑、图鉴、存档或测试统计。
- 卡牌包含吸血、护盾、易伤、范围减速、持续伤害、处决、连锁和多套跨流派组合。
- “禁忌洞见”可叠加到 5 级：每次完成正常选牌都会按 20% / 28% / 35% / 43% / 50% 判定，触发后固定追加一次四选一并牺牲当前屏障生命的 50%；追加选择本身不会再次触发，随后会准确返回开局、波末或限时奖励的原流程。
- 限时猎物从第 3 波开始出现并随进度增至每波最多 5 个；初始基础击杀窗口为 34 秒，随后每波缩短 0.75 秒、最低 8 秒，生命和减伤也会逐步提高。“悬赏信号增幅”使每 20 / 15 / 10 个敌人额外获得一次 10% 的奖励敌人生成判定；延时、削减生命和破防三条特殊卡分支集齐后可合成“悬赏统御协议”。
- 炮塔群共用一座有耐久的浅圆弧玻璃屏障；黄色护盾先承伤，随后扣除蓝色屏障。屏障就是唯一生命线，归零立即失败；支援炮塔负责在失守前修复屏障并补充黄色护盾。
- 五种攻击炮塔都有前线子炮塔卡牌：子炮塔会部署到敌军附近并提供对应火力或控制。默认敌军不会绕路追逐，只攻击进入自身攻击范围的子炮塔；获得“引力诱捕器”后才会在有限半径内改变路线。支援后期可修复全部子炮塔。
- 每座攻击炮塔独占控制面板一行，并以四个单选项设置“最近、最远、血最多、血最少”攻击优先级；支援炮塔显示为全屏自动支援。
- 每种进攻炮塔的专属射程卡最多 5 级，沿用旧版 6% / 13% / 22% / 34% / 全屏成长曲线；遗物带来的击杀射程成长在其后额外相加。前线小型子炮塔按继承比例共享实际射程，鼠标悬停会显示主炮当前范围、遗物成长与受到的射程压制。
- 普通敌人不显示血条，而是随剩余生命缩小；首领保留血条，大型核心首领另有状态栏。易伤、曝光、光锢、燃烧和减速使用独立状态显示，曝光会同时标出层数与生命上限降幅；燃烧数字按短时间窗口合并，不再出现大量 0。
- 敌方单位默认使用天体美术：小行星、彗星、卫星、恒星、中子星和黑洞；恒星具有日冕、耀斑与表面纹理，黑洞使用事件视界、光子环、引力透镜和吸积盘分层表现。设置中可切换回战术单位外观。
- 每一波至少生成一颗大型 Boss；每 3 波固定出现黑洞首领，在金冕、蓝白、紫极和暗红四种体积云层材质中轮换。黑洞等级随节点提高，生命与碎防压力同步成长，可见直径随等级缓慢增加但最多为战场宽度的一半，水平、俯仰和滚转角在安全区间内随机。
- 所有大型 Boss 出场后的前 5 秒处于无敌状态，完全免疫伤害、易伤、曝光、减速、冻结、眩晕、光锢和破碎，并显示护盾环与倒计时。保护结束后，普通减速、冻结和眩晕仍对 Boss 无效，但三张激光短控卡施加的“光锢”可以生效且持续时间减半；黑洞额外免疫电离诱引和子炮塔嘲讽。
- 大部分普通敌军会一边推进一边发射实体弹幕；恒星单位周期释放覆盖全体友军的辐射环，黑洞会先预警、再向屏障发射高能伽马射线。
- 第 3 波起会出现裂殖增生舰，死亡后分裂成多个高速尖晶，且敌军总量随波次上升。导弹的爆炸半径、额外齐射与蜂群分裂弹会优先处理密集敌群；“裂群清算协议”可让裂殖单位触发连锁殉爆。
- 黑洞 Boss 不会随剩余生命缩小；击破时不使用通用爆炸，而是让事件视界、吸积盘与体积云带分层雾化、拉散并烟消云散。
- 第 8 波起敌方远程单位会停下并直接攻击最终防线。
- 取消金币与军械商店；卡池按子弹、激光、导弹、冰霜、电弧、支援、特殊七大类组织，并采用 ★1–★6 的星级概率系统。
- ★4 卡牌开始解锁六座炮塔主动技能；点击炮塔或按 1–6 释放。★5 提供冷却与效果分支，★6 提供冰霜→导弹、激光→电弧、支援→子弹的时序连携。
- 卡牌图鉴按独立等级档案显示所有可获得卡牌；同一系列的 I / II / III 等等级各自保留固定名称与效果，不会因后续升级改写旧卡内容。
- 战斗统计的简易模式按六座炮塔汇总，详细模式按卡牌系列合并全部等级；可切换全部敌人、具体 BOSS 或小怪合计。日志逐敌保存炮塔类别、具体来源、直接/间接伤害和卡牌系列伤害。超过千级的面板数值和飘字统一使用 `k / m / b / t` 等紧凑单位。
- 导弹炮拥有并列发射架、蜂群分裂弹头与饱和火力协议：额外导弹优先攻击不同目标，每枚大型导弹还能分裂出不会继续递归的微型制导弹；三条分支成型后每第 4 轮齐射追加镜像弹幕。
- 电弧炮基础伤害进一步降至 4.4；易伤上限调整为 6 层、每层 12%，额外伤害仍归入易伤提供者，但不再在统计中压过主输出炮塔。
- 寒冰破碎与火焰破碎可分别由冰霜炮、导弹炮概率施加；双标记触发高额局部热震 AOE，伤害在两座炮塔之间平摊。易伤带来的额外伤害会计入施加易伤的炮塔。
- 组合牌同时归入所有参与炮塔的标签，并用对应颜色渐变显示。“低温电离桥 / 折光制导桥 / 弹巢维修桥”单独收益刻意偏低，三张全部集齐后解锁六塔共有的“六相坍缩协议”，形成随波次成长的全域质变。
- 所有带“特殊”标签的卡牌使用青、蓝、紫、玫红和金色组成的多彩毛玻璃卡面，不再与普通紫色功能牌混淆。
- 背景音乐按指定的 14 首 Melodysheep 曲目顺序循环，设置中可切换随机播放；背景音乐和战斗音效可独立开关。
- 设置面板使用带遮罩和关闭按钮的居中弹窗，支持 UI 字体缩放、选卡时是否暂停、敌军外观和音乐播放方式。

## 账号与存档

- 游玩前必须创建或登录本机账号；4 位口令仅保存 SHA-256 摘要，不保存明文。
- 不同账号的存档和最佳纪录相互隔离。
- 普通本机账号可在账号面板中二次确认后永久删除；测试账号与设计账号受保护。
- 下次进入会默认定位到上次登录账号，并显示上次战局。
- 每次全新开局或确认重新开始都会先直接获得 3 张互不重复的随机卡牌（随机池包含稀有卡），再获得 5 轮连续四选一，然后进入第 1 波；实测完成后共持有 8 张卡牌。
- 账号记录最高已清波次。重新开局时可从 `最高已清波次 - 5` 附近快速部署：手动补发数量按“跳过波次 + 预计奖励敌人 + 基础 5 轮 + 每跳过 5 波额外 1 轮”计算；全自动随机部署在该数量上再额外获得 8 张随机合法卡牌。
- 支持手动保存、每 10 秒自动保存、波次节点保存、切后台保存和离开页面前保存；窗口失焦或切换标签页不会自动暂停战斗。
- 登录后可直接“加载存档”，也可“放弃并重开”；游戏内左侧控制台始终提供独立的载入存档按钮。
- 当前静态版本使用浏览器 `localStorage`，不会跨设备同步，也不会上传口令或战绩。
- 内置“测试账号”的口令固定为 `1111`；登录后除各阶段构筑预设外，还提供第 5 波和第 40 波两档“满卡无敌压力”：敌我攻击、弹道和联动照常运行但不扣生命，敌军仅在实际触及屏障时移除，用于排除生存差异并复现前期密集潮与后期全系统性能负载。
- 内置“设计账号”的口令固定为 `2222`；登录后直接打开卡牌图鉴，不进入战局。选中任意卡牌可登记删除建议、目标星级、数值建议与设计备注，并下载当前建议日志 JSON；这些建议不会直接改写卡牌数值或玩家存档。

## 操作

- 左侧控制台：保存、载入、暂停、重新开始、背景音乐、战斗音效、设置、账号与波次状态。重新开始带二次确认，确认后清除当前战局并从第 1 波部署，但保留账号最高纪录与快速部署进度。
- 左侧炮塔阵列：每座炮塔一行，进攻炮塔直接选择四种攻击优先级；屏障与黄色护盾数值只显示在战场圆弧中央。
- 右侧控制台：常驻 DPS/HPS 分色计量表、卡牌图鉴和说明。
- 窄竖屏：点击左右边缘按钮打开对应抽屉，点击战场收起。
- `空格`：暂停或继续。

## 技术

游戏由原生 HTML、CSS 和 Canvas 2D 构成，无第三方运行依赖、无构建步骤，可以直接部署到 GitHub Pages。战斗画面跟随浏览器 RAF 逐帧绘制，避免 144 Hz 显示器上以简单 60 FPS 门限形成约 48 FPS 的不均匀节奏；暂停、登录和静态界面才降到约 18 FPS。高质量实验室仍用 `v35-030-wide-zoom` 的 WebGL2 程序化光路与体积云着色器生成母版；捕获模式由着色器直接输出 Alpha，并从 384×216 离屏画布读取像素，不再通过网页截图制作素材。游戏运行时采用专业 VFX 分层：程序化不透明事件视界、四色 48 相位透明 WebP 吸积盘 Flipbook、左右光子环和独立消散粒子。默认一周为 9.6 秒，旋转速度是上一版的一半；相邻两帧线性混合以保持丝滑，测试页仍可在 0.20×–1.60× 调速。常规游戏会提前解码下一种首领色系，最多保留两套素材；游戏内不再积分光路或实时运行 HDR/Bloom。

程序化母版与直出接收器已一并保存在 `tools/blackhole-vfx-preview.html` 和 `tools/receive-black-hole-assets.mjs`。批量模式会在约数秒内直接生成四套 8×6 Flipbook 与海报；最终边界审计保证四色素材左右各保留至少 13px 透明安全区、没有不透明像素贴边。
