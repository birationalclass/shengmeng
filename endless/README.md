# 无尽 · ENDLESS

《无尽》是一款原创、零付费的竖屏无尽防线游戏。它只复用了既有项目的“研究 → 设计 → 实现 → 浏览器验收 → GitHub Pages 发布”流程，不复用《疆域争锋》的题材或游戏内容。

## 运行

在本目录启动静态服务器：

```powershell
python -m http.server 4173
```

然后访问 <http://localhost:4173>。

## 当前玩法

- 中央战场保持纯净：宽屏时状态、控制与炮塔阵列位于左侧，常驻 DPS/HPS、卡牌和军械位于右侧；窄竖屏使用左右抽屉。
- 开局只有子弹主炮；激光、导弹、冰霜、电弧和支援炮塔必须通过选牌部署，六座炮塔统一位于战场底部。
- 每波结束固定三选一；牌池会优先延续现有构筑，并保证炮塔解锁与新方向仍有机会出现。
- 卡牌包含吸血、护盾、易伤、范围减速、持续伤害、处决、连锁和多套跨流派组合。
- “禁忌洞见”会让普通波次增加一次选牌机会；选择追加卡牌时牺牲当前生命值 50%。
- 限时猎物的基础击杀窗口为 28 秒；及时击杀后会让下一次三选一额外增加一次刷新。
- 炮塔群共用一座有耐久的浅圆弧玻璃屏障；敌方攻击先消耗屏障，再依次进入护盾和最终防线生命。耐久下降会产生渐进裂纹，恢复时裂纹同步愈合。
- 每座炮塔独占控制面板一行，并以四个单选项设置“最近、最远、血最多、血最少”攻击优先级。
- 鼠标悬停炮塔会显示真实攻击范围；每种炮塔都有可叠加的专属射程卡。
- 普通敌人不显示血条，而是随剩余生命缩小；首领保留血条。
- 第 8 波起敌方远程单位会停下并直接攻击最终防线。
- 击杀敌人获得本局金币，可购买基础攻击力、暴击率、暴击伤害和攻击速度。
- 卡牌图鉴显示所有可获得卡牌、当前等级和可合成组合。
- 战斗统计按伤害来源着色，记录总伤害、当前 DPS、总治疗和当前 HPS。
- 背景音乐按指定的 14 首 Melodysheep 曲目顺序循环，设置中可切换随机播放；背景音乐和战斗音效可独立开关。
- 设置面板支持 UI 字体缩放，以及选卡时是否暂停战斗。

## 账号与存档

- 游玩前必须创建或登录本机账号；4 位口令仅保存 SHA-256 摘要，不保存明文。
- 不同账号的存档和最佳纪录相互隔离。
- 下次进入会默认定位到上次登录账号，并显示上次战局。
- 账号记录最高已清波次。重新开局时可从 `最高已清波次 - 5` 附近快速部署，并按跳过波次和奖励敌人出现次数补发多轮三选一与估算金币。
- 支持手动保存、每 10 秒自动保存、波次节点保存、切后台保存和离开页面前保存。
- 登录后可直接“加载存档”，也可“放弃并重开”；游戏内左侧控制台始终提供独立的载入存档按钮。
- 当前静态版本使用浏览器 `localStorage`，不会跨设备同步，也不会上传口令或战绩。

## 操作

- 左侧控制台：保存、载入、暂停、背景音乐、战斗音效、设置、账号与防线状态。
- 左侧炮塔阵列：每座炮塔一行，直接选择四种攻击优先级，并显示全域屏障耐久。
- 右侧控制台：常驻 DPS/HPS 分色计量表、卡牌图鉴、军械商店和说明。
- 窄竖屏：点击左右边缘按钮打开对应抽屉，点击战场收起。
- `空格`：暂停或继续。

## 技术

游戏由原生 HTML、CSS 和 Canvas JavaScript 构成，无第三方运行依赖，无构建步骤，可以直接部署到 GitHub Pages。
