# 无尽 · ENDLESS

一款原创的零付费无尽防线浏览器游戏。项目只复用了既有本地项目的“调研 → 设计 → 实现 → 测试 → GitHub Pages 发布”工作流程，不复用《疆域争锋》的领地、据点、派兵或关卡内容。

## 运行

直接双击 `index.html`，或在本目录运行：

```powershell
python -m http.server 4173
```

然后访问 <http://localhost:4173>。

## 核心玩法

- 五座炮台自动阻击从上方逼近最终屏障的星潮。
- 点击战场可下达 5 秒集火标记，集中处理真正的高威胁目标。
- 歼敌积攒“极限火力”，充满后手动释放全炮台爆发。
- 原创背景曲《终线脉冲·战区版》是一首 2 分钟、48 小节的立体声射击游戏配乐，包含压迫铺垫、战斗推进、战术降压、强化战斗与循环收尾五个段落。
- 每波结束三选一卡；每波有一次免费刷新。
- 选牌算法优先提供已有流派升级和组合组件，减少无关卡牌污染牌池。
- 雷、霜、火、弹道、生存、超频六类卡牌可以交叉组成六种完整回路。
- 每 5 波出现精英，每 10 波出现首领；敌人属性与数量无限成长。
- 游玩前必须创建或登录本机账号；4 位口令只保存摘要，不保存明文。
- 每个账号的最佳纪录和进行中存档完全隔离；下次登录会自动选中上次账号，并直接展示上次游玩记录。
- 支持顶部手动保存、每 8 秒自动保存、波次节点保存和离开页面前保存；可加载续玩，也可放弃记录从头开始。
- 账号与存档只用于保存进度，不提供永久战力养成。

## 操作

- 鼠标或触摸：点击战场设置集火标记。
- “极限火力”充满后点击底部按钮释放。
- `空格`：暂停 / 继续。
- `R`：返回开局界面。
- 右上角可保存、切换账号、切换 1× / 1.5× / 2× 速度；“♫”与“✦”分别独立控制背景音乐和战斗音效。

全部画面由 Canvas 与 CSS 实时绘制，无第三方依赖，可直接部署到 GitHub Pages。

> 当前版本是 GitHub Pages 可直接运行的纯静态版，因此账号和存档保存在当前浏览器的 `localStorage` 中，不会跨设备同步，也不会上传口令或战绩。
