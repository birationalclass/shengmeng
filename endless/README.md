# 无尽 · ENDLESS

《无尽》是一款原创、零付费的竖屏无尽防线游戏。它只复用了既有项目的“研究 → 设计 → 实现 → 浏览器验收 → GitHub Pages 发布”流程，不复用《疆域争锋》的题材或游戏内容。

## 运行

在本目录启动静态服务器：

```powershell
python -m http.server 4173
```

然后访问 <http://localhost:4173>。

## 当前玩法

- 中央战场保持纯净：宽屏时状态和控制位于左侧，常驻 DPS/HPS、卡牌、军械和炮塔阵列位于右侧；窄竖屏使用左右抽屉。
- 开局只有中央子弹主炮，激光炮、导弹炮、冰霜炮和电弧炮必须通过选牌部署。
- 每波结束选一张卡；牌池会优先延续现有构筑，并保证炮塔解锁与新方向仍有机会出现。
- 卡牌包含吸血、护盾、易伤、范围减速、持续伤害、处决、连锁和多套跨流派组合。
- “禁忌洞见”会牺牲当前生命值 50%，永久增加以后每次选牌的候选数。
- 限时猎物在倒计时内击杀后，会让下一次选牌额外增加一个候选。
- 第 8 波起敌方远程单位会停下并直接攻击最终防线。
- 击杀敌人获得本局金币，可购买基础攻击力、暴击率、暴击伤害和攻击速度。
- 卡牌图鉴显示所有可获得卡牌、当前等级和可合成组合。
- 战斗统计按伤害来源着色，记录总伤害、当前 DPS、总治疗和当前 HPS。
- 原创背景音乐《终线脉冲·战区版》长 2 分钟，背景音乐和战斗音效可独立开关。

## 账号与存档

- 游玩前必须创建或登录本机账号；4 位口令仅保存 SHA-256 摘要，不保存明文。
- 不同账号的存档和最佳纪录相互隔离。
- 下次进入会默认定位到上次登录账号，并显示上次战局。
- 支持手动保存、每 8 秒自动保存、波次节点保存、切后台保存和离开页面前保存。
- 登录后可直接“加载存档”，也可“放弃并重开”。
- 当前静态版本使用浏览器 `localStorage`，不会跨设备同步，也不会上传口令或战绩。

## 操作

- 左侧控制台：保存、暂停、背景音乐、战斗音效、账号与防线状态。
- 右侧控制台：常驻 DPS/HPS 分色计量表、卡牌图鉴、军械商店、说明和炮塔阵列。
- 窄竖屏：点击左右边缘按钮打开对应抽屉，点击战场收起。
- `空格`：暂停或继续。

## 技术

游戏由原生 HTML、CSS 和 Canvas JavaScript 构成，无第三方运行依赖，无构建步骤，可以直接部署到 GitHub Pages。
