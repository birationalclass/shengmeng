# 疆域争锋 · Frontier Claim

一款受经典轻量即时领地策略玩法启发的原创浏览器游戏。它保留了“据点自动产兵 → 沿道路派兵 → 攻占并扩张”的核心乐趣，同时使用原创名称、关卡、视觉、数值和代码。

## 运行

最简单的方式是直接双击 `index.html`。也可以在当前目录启动本地服务器：

```powershell
python -m http.server 4173
```

然后打开 <http://localhost:4173>。

## 操作

- 在友方据点上按住鼠标，拖出行军箭头，指向目标后松开才会派兵。
- 从空地按住拖动可拉出选框，选中区域内所有友方据点；随后从任一所选据点拖向目标即可集体出兵。
- 部队可沿连续的友方据点自动中转，不要求出发点与最终目标直接相邻。
- `Shift + 点击` 可增减多选据点。
- 派兵比例可选一半或全部。
- 双击己方据点，或使用底部按钮升级。
- 选择单个己方据点后可自由改建；改建会牺牲全部驻军并重置为 1 级。
- `A` 选择全部、`U` 升级、`空格` 暂停、`R` 重开、`右键` 取消选择。

## 已实现

- 大地图式战役主界面，包含 8 张原创地图、逐关解锁、本地最佳成绩和星级记录
- 新兵 / 将领 / 统帅三档难度
- 村落、要塞、箭塔、驿站、军械所五类据点，全部可升至 4 级
- 箭塔不自动产兵；逐级提升伤害与射程，3 级附带范围减速，4 级每击杀 4 名敌兵俘虏 1 名，累计 10 名后自动突袭可达目标中驻军最少者
- 两支可互相争夺领地的电脑军团
- 自动产兵、容量、升级、战力、防御、塔防射击和行军速度系统
- 建筑自产到当前等级软上限后停止；外部增援可以突破软上限，但超限后每个游戏秒损失 1 名驻军
- 点击、框选、Shift 多选、增援、50% / 100% 派兵
- 本机个人账号：用户名 + 4 位口令，独立保存关卡、星级、设置和战绩
- 设置面板内置完整建筑等级数据；暂停不遮挡战场，并提供 1× / 1.5× / 2× 速度、合成音效和响应式界面

不需要安装依赖，所有画面均由 Canvas 与 CSS 实时绘制。账号数据仅保存在当前浏览器的 `localStorage` 中，不提供云同步。
