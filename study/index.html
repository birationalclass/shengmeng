AT·001 / ALGEBRAIC TOPOLOGY

为什么圆与 8 字形都是 ENR？

主题
Retracts · CW complexes
目标
从定义看到邻域如何收缩
关键词
ENR · regular neighborhood

r

DEFINITION / 定义

一个空间 X 是 ENR，如果它能嵌入某个有限维欧氏空间，并且是其中某个开邻域的 retract。

X ⊂ U ⊂ ℝN，r : U → X，r|X = idX

EXAMPLE 01

圆：沿半径投影。

把单位圆放在平面中，取不经过原点的开圆环作为邻域。每个点都沿着通过原点的射线移动到单位圆上。

U = { x ∈ ℝ² : 1 − ε < ‖x‖ < 1 + ε } r(x) = x / ‖x‖ 在 S¹ 上有 ‖x‖ = 1，因此 r(x) = x。
  1. 开邻域圆环 U 在 ℝ² 中是开集，并包含 S¹。
  2. 连续映射U 不含原点，所以除以 ‖x‖ 没有问题。
  3. 固定目标圆上的每一点保持不动，因此 r 是 retraction。

EXAMPLE 02

8 字形：把有限图的厚邻域压回骨架。

8 字形是一个顶点加两条 loop 的有限 CW complex。把它作成平面中的有限折线图 G，并取足够小的 regular neighborhood N(G)。这个厚邻域可以强变形收缩到图本身。

  2. 顶点附近取一个小圆盘，把它与四条细带相容地压到中央顶点与入射边。
  3. 拼合有限多个局部收缩相容地拼成 N(G) → G 的 retraction。

THE BIG PICTURE

两种证明，同一个核心。

A / 直接构造找到开邻域 U→写出或构造 r : U → X→ENR圆的径向投影属于这一条路线。
B / 组合结构识别为有限 CW complex→嵌入有限维欧氏空间→ENR8 字形属于这一条路线。
注意

“有奇点”并不妨碍成为 ENR。8 字形的交点不是一维流形点，但整个空间仍是有限 CW complex。真正危险的是坏的局部拓扑，例如 Hawaiian earring 在积聚点不局部可缩。
