# 难民营设计

独立的三维布局编辑模块，保留原数学难民营场景。

- 默认建筑群向东移动30米，网格10米；已有保存不会重复东移。
- 右键直接选中并水平拖动整组建筑，默认左键控制视角；可选左键编辑模式用于调整单件装饰；金色包围框提示选中对象。桌、沙发、树木和报告厅座椅的关联部件一起移动；未分组构件可单独调整。
- 可添加海上亭阁、图书馆、教学楼、树木、帆船、长椅。这些新增建筑为可进一步设计的基础模块。
- 连桥从平台四侧选择锚点，在平台包络外按最短直角路线绕行；无可行路线时提示。拖拽完成后重算，避免每帧寻路。
- 保存到当前浏览器，JSON包含建筑、新增元素、装饰偏移和连接关系。旧版布局可导入。线上和本地为不同源，使用JSON转移布局。
- 设计工具完全静态运行，无需服务器数据库。原场景的视频等外围服务仍遵循原模块限制。

验证：Node运行 layout-data.test.mjs、design-routing.test.mjs；浏览器检查添加、拖拽、高亮、保存恢复。
