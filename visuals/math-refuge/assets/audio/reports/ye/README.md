# 叶东报告合成旁白

AI 合成，非叶东或沈腾本人录音。

使用上传者标注的沈腾公开参考音频，以 Qwen3-TTS 条件生成；未重新训练演员模型，标签不作为独立身份验证。

选择报告后按章节加载，网页开场不请求报告语音。26 章音频，总长 55.25 分钟。28 块正文板共 164 个语义行（含标题），每行保存源内容、口播、实际音频和书写区间；分段公式中的分支均口述。

换板只保留一句承接；解释和证明放在相应行写出后。时间轴采用解码后的音频样本，无长静音填时长。

论文：https://arxiv.org/abs/2607.23057（CC BY 4.0）。

开场问候从第零秒开始；标题与署名约 13 秒自然书写，完成后才介绍题目。三列黑板下方各有中英切换与播放图标，加载使用实测字节圆环；离开报告厅临时暂停，手动暂停不会因重入自动恢复。可关闭的临时激光指示按语义源行、字形范围和可获得的语音词时间戳定位，不写进板书纹理。
