METHOD / VERIFICATION

不同几何流，按讲稿
分别离散计算。

立方体和环面使用 BGN 曲面扩散；“方正双孔框 → 8 字曲面”使用讲稿第 28 页的 relaxed-MDR Willmore 流；“扁椭球 → 红细胞”使用第 41 页保面积、保体积的 Helfrich 流。所有案例都保持固定三角连通关系，浏览器仅在相邻数值状态间显示插值。

01 / BGN SURFACE DIFFUSION

在旧曲面 Sm 上求 Xm+1 与 Hm+1：

⟨ ((Xm+1−Xm)/τ)·nm, φ ⟩h − ⟨ ∇SHm+1, ∇Sφ ⟩ = 0
⟨ Hm+1nm, η ⟩h + ⟨ ∇SXm+1, ∇Sη ⟩ = 0

第一式给出表面扩散的法向速度；第二式把平均曲率向量与新位置耦合。质量集中的面法向耦合产生隐式切向运动。

02 / RELAXED-MDR WILLMORE FLOW

双孔框案例按 Zhao 2026 的全离散混合系统求速度 wm+1、曲率向量 km+1 与两个乘子：

⟨ w·ν, χ·ν ⟩h − ℬhm(km+1;χ) + ⟨ Pχ,p ⟩h + α⟨∇χ,∇p⟩ = 0
⟨ km+1,η ⟩h + ⟨∇(id+τwm+1),∇η⟩ = 0

这里 α=10，τ=10−3；relaxed-MDR 只选择切向网格速度，Willmore 法向速度仍决定几何演化。

03 / CONSTRAINED HELFRICH FLOW

红细胞案例在同一 mixed system 中加入面积、体积两个全局乘子：

⟨ w,ν ⟩h = 0
⟨ θAν,w ⟩h = 0

这里 κ̄=0、α=10、τ=10−3、T=0.2；两个约束阻止扁椭球简单收缩成球，弯曲能下降后得到双凹平衡形。

ENERGY表面积单调下降

每一步验证 Wm+1 + τ‖∇SHm+1‖² ≤ Wm。

TOPOLOGY定向始终保持

每条轨迹都保持固定连通关系和曲面亏格，也未执行重网格。

立方体：BGN 曲面扩散完整算法

下面不是动画补间说明，而是生成当前页面全部数值状态的实际离散算法。切换上方案例后，这一节同步切换。

Γ⁰：2×2×2 立方体边界K=602J=1,200τ=5×10−5M=320T=0.016
  1. 建立曲面有限元空间。

    令 Γm=⋃σ∈𝒯σ，Shm=span{φi}。对每个三角形 σ=(qi,qj,qk) 计算面积 |σ|、外法向 νσ 和常值基函数梯度 ∇sφi。装配

    Aij=∑σ|σ|∇sφi·∇sφj,　Ni=∑σ∋i(|σ|/3)νσ,　B=[diag(Nx) diag(Ny) diag(Nz)]。
  2. 解一个线性 BGN 时间步。

    记 A3=diag(A,A,A)，未知量是新顶点坐标 Xm+1∈ℝ3K 与离散标量平均曲率 Hm+1∈ℝK。稀疏直接求解

    [ B/τ　−A ; A3　BT ] [ Xm+1 ; Hm+1 ] = [ BXm/τ ; 0 ]。

    这正是质量集中弱式 ⟨(Xm+1−Xm)/τ·νm,φ⟩h−⟨∇Hm+1,∇φ⟩=0 与 ⟨Hm+1νm,η⟩h+⟨∇Xm+1,∇η⟩=0。

  3. 更新并逐步验算。

    保持三角形索引 𝒯 不变，置 Γm+1=Xm+1(Γ⁰)，重复至 m=M−1。每步计算面积 Wm、有向体积 Vm、qmin 与能量缺陷 Wm+1−Wm+τ(Hm+1)TAHm+1。

  4. 输出与显示。

    保存 321 个真实时间层。选择“三角形 1→4”时，对每条原共享边只生成一个中点，并以 (a,ab,ca)、(ab,b,bc)、(ca,bc,c)、(ab,bc,ca) 替换原三角形；顶点位置逐时间层取端点平均，不改变离散曲面或算法指标。

Γ⁰：7×4×1 双方孔框K=310J=624α=10τ=10−3M=5,000T=5
  1. 构造亏格 2 初值并初始化曲率向量。

    从 7×4×1 实心长方体中沿厚度方向挖去两个 2×2×1 方孔，取其定向边界 Γ⁰；Euler 示性数 χ=−2，故 g=2。用连续分片线性元和质量集中矩阵 M3，求

    k⁰=−M3−1A3X⁰，　Eh⁰=½(k⁰)TM3k⁰。
  2. 在旧曲面上装配 relaxed-MDR 算子。

    逐三角形装配刚度 A3、质量 M3、法向质量 Mν、法向耦合 D，以及 C=MP+αA3，其中 P=I−ν⊗ν。零自发曲率时，弯曲能低阶项按

    Rhm(k;χ)=∫Γᵐ[(∇s·k)(∇s·χ)−(∇sk)T:((∇sχ+(∇sχ)T)P)+½Ih(|k|²)∇s·χ]。
  3. 解四块对称混合系统。

    未知量依次为速度 wm+1、曲率向量 km+1、标量乘子 λm+1 和 MDR 乘子 pm+1。每一步求解 Zhao (4.8)/(5.1) 的闭曲面、κ̄=0 特例：

    KW[w;k;λ;p]=[fw;fk;0;0]，　KW=[ Mν　−A3　0　C ; −A3　−M3/τ　0　0 ; 0　0　0　D ; C　0　DT　0 ]，
    fw=Rhm(km;·)，　fk=A3Xm/τ。
  4. 更新、校验并编码。

    Xm+1=Xm+τwm+1，随后减去顶点均值以固定无关紧要的整体平移。保持 𝒯 不变，检查 Eh、有向体积、qmin、三角形定向与 χ。完整档案每 5 步保存一次（1,001 层）；网页无损保留每 10 步的 501 层并连续插值。1→4 仅作共享中点显示剖分。

Γ⁰：亏格 1 环面K=480J=960τ=2×10−5M=260T=0.0052
  1. 生成定向周期网格。

    用两个周期参数方向三角剖分环面，合并周期边界顶点并统一外向定向。验证 V−E+F=0，因此 χ=0、g=1；此后不改变顶点邻接关系。

  2. 装配 BGN 曲面有限元矩阵。

    在 Γm 上逐三角形计算 |σ|、νσ、∇sφi，形成 Aij=∑|σ|∇φi·∇φj、结点面积法向 Ni=∑(|σ|/3)νσ、B=[diag(Nx) diag(Ny) diag(Nz)] 与 A3=diag(A,A,A)。

  3. 推进 260 个隐式时间步。
    [ B/τ　−A ; A3　BT ] [ Xm+1 ; Hm+1 ] = [ BXm/τ ; 0 ]，　Γm+1=Xm+1(Γ⁰)。

    该系统同时给出表面扩散的法向速度和由弱曲率式诱导的切向网格运动；环孔不会被填掉，因为 𝒯 的拓扑固定。

  4. 验算与显示。

    保存全部 261 层，逐层检查面积单调性、离散耗散不等式、有向体积漂移、qmin 和面定向。细网格把每个原三角形按共享边中点精确拆成四个共面的子三角形，所有时间和几何指标沿用原 PFEM 解。

Γ⁰：4×4×1 扁椭球K=572J=1,140κ̄=0α=10τ=10−3M=200T=0.2
  1. 初始化离散 Helfrich 能。

    对 4×4×1 扁椭球作经纬三角剖分并统一外向定向。装配 M3、A3，置 k⁰=−M3−1A3X⁰。因 κ̄=0，Eh⁰=½(k⁰)TM3k⁰。

  2. 形成 Willmore–MDR 基础系统。

    与双孔框相同，逐步在 Γm 上装配 Mν、A3、M3、D、C=MP+αA3 和 Rhm，得到四变量矩阵 KW 与右端 f=[Rhm;A3Xm/τ;0;0]。

  3. 加入面积和体积两个全局约束。

    质量集中的结点法向为 νh,p,i=Ni/mi，令 θA,im=kim·νh,p,i。在速度分量上装配 qA,i=θA,imNi、qV,i=Ni，Q=[qA,qV]，求增广系统

    [ KW　Q ; QT　0 ] [ x ; (λA,λV) ] = [ f ; 0 ]。

    末两行就是 ⟨θAν,w⟩h=0 和 ⟨ν,w⟩h=0，即离散面积与体积的一阶变化为零。

  4. 推进到双凹平衡并报告误差。

    Xm+1=Xm+τwm+1，共 200 步，固定 𝒯 并保存 201 层。逐层记录 Eh、A/A⁰−1、V/V⁰−1、qmin 和定向；当前网页轨迹中能量 76.777→49.185，最大面积/体积变化分别为 0.538%/0.166%。1→4 模式只细分同一数值曲面。
