立方体和环面使用 BGN 曲面扩散；“方正双孔框 → 8 字曲面”使用讲稿第 28 页的 relaxed-MDR Willmore 流；“扁椭球 → 红细胞”使用第 41 页保面积、保体积的 Helfrich 流。所有案例都保持固定三角连通关系，浏览器仅在相邻数值状态间显示插值。

01 / BGN SURFACE DIFFUSION

在旧曲面 Sm 上求 Xm+1 与 Hm+1：

⟨ ((Xm+1−Xm)/τ)·nm, φ ⟩h − ⟨ ∇SHm+1, ∇Sφ ⟩ = 0
⟨ Hm+1nm, η ⟩h + ⟨ ∇SXm+1, ∇Sη ⟩ = 0

第一式给出表面扩散的法向速度；第二式把平均曲率向量与新位置耦合。质量集中的面法向耦合产生隐式切向运动。

02 / RELAXED-MDR WILLMORE FLOW

双孔框案例按 Zhao 2026 的全离散混合系统求速度 wm+1、曲率向量 km+1 与两个乘子：

⟨ w·ν, χ·ν ⟩h − ℬhm(km+1;χ) + ⟨ Pχ,p ⟩h + α⟨∇χ,∇p⟩ = 0
⟨ km+1,η ⟩h + ⟨∇(id+τwm+1),∇η⟩ = 0

这里 α=10，τ=10−3；relaxed-MDR 只选择切向网格速度，Willmore 法向速度仍决定几何演化。

03 / CONSTRAINED HELFRICH FLOW

红细胞案例在同一 mixed system 中加入面积、体积两个全局乘子：

⟨ w,ν ⟩h = 0
⟨ θAν,w ⟩h = 0

这里 κ̄=0、α=10、τ=10−3、T=0.2；两个约束阻止扁椭球简单收缩成球，弯曲能下降后得到双凹平衡形。

ENERGY表面积单调下降

每一步验证 Wm+1 + τ‖∇SHm+1‖² ≤ Wm。

TOPOLOGY定向始终保持

每条轨迹都保持固定连通关系和曲面亏格，也未执行重网格。
