# 群数独 · 八域之书

独立可视化模块。棋盘是三维场景中的实体表面，直接点击格子后用数字键或工具栏落子，不弹出游戏窗口。八区的装饰建筑围绕棋盘，随阶数增加逐步丰富。设置可切换手绘羊皮纸（山脉、河流、湖泊、森林与道路）和机械地图。羊皮纸三维地图、木质棋盘、黄铜坐标与机械城邦沿用测试模块的建筑细节和桥梁构件；原课程入口不变。所有资源在本网站加载，本模块不播放音频。

## 八个区域

每区对应一个 2×2 至 9×9 乘法表。2、3、5、7 阶用循环群；4 阶用 C₂×C₂；6 阶用 S₃；8 阶用 D₄（8 阶正方形对称群）；9 阶用 C₃×C₃。重新编号打散规律，单位元标为 n，而非 1。6、8 阶不交换。

每行每列恰好包含 1,…,n，还需满足结合律；没有普通数独的宫格限制。线索生成及完整逐步唯一性证明复用课程的 associativity-sudoku.js：每一步由行列剩余元素或一个已知的结合律等式强制确定，且构造出的群表证明解存在。最终检查全部 n³ 个三元组。

3×3 通关后解锁单位元卡，只将单位元数字标红。其余逆元、消去律、结合律卡引导读表与推导。八区可直接访问，通关点亮地图。进度保存在本机 localStorage；读取时重新验证线索和完整表，不信任单独的通关标志。存储被禁用时当前会话仍可游戏。
