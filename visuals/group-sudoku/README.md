# 群数独 · 八域之书

独立可视化模块。棋盘是三维场景中的实体表面，直接点击格子后用数字键或工具栏落子，不弹出游戏窗口。八区的装饰建筑围绕棋盘，随阶数增加逐步丰富。设置可切换手绘羊皮纸（山脉、河流、湖泊、森林与道路）和机械地图。羊皮纸三维地图、八种材质棋盘、黄铜坐标与机械城邦沿用测试模块的建筑细节和桥梁构件；原课程入口不变。所有资源在本网站加载，背景音乐可在设置中控制。

## 八个区域

每区对应一个 2×2 至 9×9 乘法表。2、3、5、7 阶用循环群；4 阶用 C₂×C₂；6 阶用 S₃；8 阶用 D₄（8 阶正方形对称群）；9 阶用 C₃×C₃。重新编号打散规律，单位元标为 n，而非 1。6、8 阶不交换。

每行每列恰好包含 1,…,n，还需满足结合律；没有普通数独的宫格限制。线索生成及完整逐步唯一性证明复用课程的 associativity-sudoku.js：每一步由行列剩余元素或一个已知的结合律等式强制确定，且构造出的群表证明解存在。最终检查全部 n³ 个三元组。

3×3 通关后解锁单位卡，填满单位元所在行与列；通关第 4 关（5×5）后解锁逆卡，根据已知 ba=e 补出 ab=e。只保留这两张操作卡，唯一解证明仍可展开阅读。给定数字为固定嵌刻字，填写数字为另一种笔迹。通关后棋盘微光亮起。八区按顺序解锁。未解锁区域只有圆盘；镜头先平稳抵达并停稳，然后独立升起棋盘，随后依次搭建设施（装饰搭建默认 15 秒，可在设置中调为 5–45 秒；镜头抵达和棋盘升起分别计时），名牌居中放在圆盘下侧的地图上；通关后放下吊桥并连续运镜至下一关。全部通关后进入宏观巡游，点击任一棋盘，经平稳运镜后重玩；重玩不收回已经获得的技能与建成的区域。进度保存在本机 localStorage；读取时重新验证线索和完整表，不信任单独的通关标志。存储被禁用时当前会话仍可游戏。设置中的“清除本地记录（Cookie）”经确认后仅删除群数独的进度、棋局与地图设置，刷新后从 2×2 重新开始，不清除本站其他模块的数据。
