ABOUT / THE MODEL

一条参数轨迹，
连续改写分形边界。

每一个像素都从复数 z₀ 出发，重复计算 zn+1 = zn² + c(t)。参数 c 沿一条由两个不同频率叠加而成的闭合曲线运动，因此 Julia 集会在连通、拉伸与碎裂之间缓慢过渡。

c(t) = 1.1 · (
  0.5 cos(0.01t) − 0.25 cos(0.02t),
  0.5 sin(0.01t) − 0.25 sin(0.02t)
)
ORIGINDesktop OpenGL study

保留原始 Python / GLSL 版的复数迭代、参数路径与双阶段调色。

RENDERINGWebGL2 + Canvas fallback

优先使用 GPU 实时计算；无 WebGL2 时自动切换到低分辨率 CPU 备用画面。
