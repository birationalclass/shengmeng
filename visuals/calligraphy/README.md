# 立体书法

Visual Lab 的独立静态模块。全屏画布、右上角图标控制、隐藏式设置与底部书写栏。无构建步骤，需通过 HTTP 提供 ES 模块和 JSON 字库。

打开页面时始终为空画布和空输入框，不从旧链接自动载入文字。输入后按「书写」或主动载入工作参数才会生成模型，同时显示平面字样。默认使用拉丝材质和较易辨认的行草；目录封面为无字抽象笔势。

- 输入 1–8 个汉字；设置内选择繁体、简体或保留原文。转换后载入对应字形。
- 平面字样从当前选中字形的边界曲线生成，不受运镜、灯光与材质影响；切换汉字、简繁、字势或载入参数时同步更新。桌面并列显示，手机使用上方平面、下方立体的布局。
- 「孟、晟」提供行草、草书和原有字形。默认行草参考 Zhi Mang Xing，保留子与皿、日与成的结构，局部承转连写；较草的 Liu Jian Mao Cao 版本继续保留。两类三维轨迹、截面与时序均独立设计。其余字明确沿用已有模型。
- 拖动旋转、滚轮缩放；旋转不暂停书写。自动运镜最后回到正面。
- 通用笔锋按曲面宽度、转向和笔画间距推断铺锋、提按、翻转与抬笔节奏；保留已有专用动作。可在「笔势 → 运笔方式」比较动态运笔与逐段显露。推断动作不会添加实体连笔，也不改变成字轮廓；自动字形仍需要单独精修。
- 设置包含两版材质、八种颜色、布光、空间笔势、逐笔显隐与来源。其余常用操作位于视角和导出菜单。
- 导出 PNG、完整书写 WebM、当前模型 OBJ/MTL ZIP、版本 4 JSON 工作参数；兼容旧版 1–3 JSON 参数。
- `H` 隐藏或恢复界面，`Esc` 关闭面板。设置页签支持左右箭头、Home、End。

## 来源与范围

模型沿用本地研究项目的手工曲面与自动造型引擎。`楊、風、天、琪、道法自然、广、孟、晟` 有逐笔设计；其余字是自动生成，不能视为已精修。孟、晟的行草与草书分别参考 Zhi Mang Xing、Liu Jian Mao Cao（SIL OFL 1.1），原型与许可位于 `assets/running/` 和 `assets/cursive/`；三维运笔为本项目重新设计，不称作字体作者的真实书写笔顺。没有取得原视频作者的源模型或工程，不宣称严格复现。

当前字形来源位于设置的「说明」，完整说明见 `references.html`。保留 `data/` 和 `vendor/` 内所有许可。输入文字和参数在浏览器本地处理。

## 目录

- `engine/`：几何、动画与模型导出。
- `vendor/`：Three.js、OpenCC.js 及许可。
- `data/`：按需读取的字形数据。
- `assets/`：参考局部、预览与作品封面。

公开模块不包含旧试验页面、视频下载或原作者的模型文件。

验证：`node --test tests/brush-plan.test.mjs tests/cursive.test.mjs tests/flat-preview.test.mjs`。检查旧版几何、新字势的连续曲面、深度变化、时间单调性、曲面有限值，以及平面投影与当前字形一致且不修改三维数据。
