# 立体书法

Visual Lab 的独立静态模块。全屏画布、右上角图标控制、隐藏式设置与底部书写栏。无构建步骤，需通过 HTTP 提供 ES 模块和 JSON 字库。

打开页面时始终为空画布和空输入框，不从旧链接自动载入文字。输入后按「书写」或主动载入工作参数才会生成模型，同时显示平面字样。默认使用拉丝材质和「衡山行书 · 02」字势；目录封面为无字抽象笔势。

- 输入 1–16 个汉字；设置内选择繁体、简体或保留原文。转换后载入对应字形。
- 新增「主页行书 · 天之道」：主页十字直接使用原始标题字库轮廓；同字族共6763字，以简体为主。原字库未收录的繁体会提示缺字，不使用其他字体替代。新增「主页双列 · 右起」，右列天之道、左列损有余而补不足，列距1.14字格，左列下错0.43字格。点击「主页 · 天之道」载入完整十字，不在打开页面时自动生成。
- 主页十字的66笔分别匹配了本字的运笔轨迹和笔触半径；按横、撇、捺等各笔的落笔、行笔、收锋、抬笔独立推进。字形表面随笔触实际到达区域生长，跨笔画的时间不再做线性混合。「笔势」可逐笔停看。其余字先将通用笔顺配准到字形后估计，尚未逐笔人工核对。
- 主页字形使用双面闭合曲面，厚度随轮廓距离变化，边缘与笔画中腹圆润相接。原字体未记录真实运笔，三维体积和书写节奏为本地重建。原始轮廓、CSS光学变换及OFL许可记录在 `assets/homepage/`。
- 平面字样从当前选中字形的边界曲线生成，不受运镜、灯光与材质影响；切换汉字、简繁、字势或载入参数时同步更新。桌面并列显示，手机使用上方平面、下方立体的布局。
- 「衡山行书 · 02」逐笔重写孟、晟、楊；琪因原字体为空字形，由本项目独立补写并明确标注。保留斜势、折肩、提按和回带，重新设计三维深度、圆润截面与书写时序。其余字沿用已有模型，未假称全部字已精修。
- 旧版行草、草书和原有字形仍可选择。「孟、晟」的行草参考 Zhi Mang Xing，较草的版本参考 Liu Jian Mao Cao；三维轨迹、截面与时序均独立设计。
- 拖动旋转、滚轮缩放；旋转不暂停书写。自动运镜最后回到正面。
- 通用笔锋按曲面宽度、转向和笔画间距推断铺锋、提按、翻转与抬笔节奏；保留已有专用动作。可在「笔势 → 运笔方式」比较动态运笔与逐段显露。推断动作不会添加实体连笔，也不改变成字轮廓；自动字形仍需要单独精修。
- 设置包含两版材质、八种颜色、布光、空间笔势、逐笔显隐与来源。其余常用操作位于视角和导出菜单。
- 导出 PNG、完整书写 WebM、当前模型 OBJ/MTL ZIP、版本 4 JSON 工作参数；兼容旧版 1–3 JSON 参数。
- `H` 隐藏或恢复界面，`Esc` 关闭面板。设置页签支持左右箭头、Home、End。

## 来源与范围

模型沿用本地研究项目的手工曲面与自动造型引擎。`楊、風、天、琪、道法自然、广、孟、晟` 有逐笔设计；其余字是自动生成，不能视为已精修。衡山行书原型来自青柳衡山官方字体，原型及缺字记录位于 `assets/kouzan/`；不包含字体文件。琪为本地补写。旧版孟、晟的行草与草书分别参考 Zhi Mang Xing、Liu Jian Mao Cao（SIL OFL 1.1），原型与许可位于 `assets/running/` 和 `assets/cursive/`。三维运笔为本项目重新设计，不称作字体作者的真实书写笔顺。没有取得原视频作者的源模型或工程，不宣称严格复现。

当前字形来源位于设置的「说明」，完整说明见 `references.html`。保留 `data/` 和 `vendor/` 内所有许可。输入文字和参数在浏览器本地处理。

## 目录

- `engine/`：几何、动画与模型导出。
- `vendor/`：Three.js、OpenCC.js 及许可。
- `data/`：按需读取的字形数据。
- `assets/`：参考局部、预览与作品封面。

公开模块不包含旧试验页面、视频下载或原作者的模型文件。

验证：`node --test tests/brush-plan.test.mjs tests/cursive.test.mjs tests/flat-preview.test.mjs tests/kouzan.test.mjs tests/homepage.test.mjs tests/stroke-order.test.mjs`（主页栅格核验需安装 `@napi-rs/canvas`，也可通过 `CALLIGRAPHY_CANVAS_MODULE` 指定模块）。检查旧版几何、新字势的连续曲面、深度变化、时间单调性、曲面有限值、缺字补写标注、主页原字形与双列比例、闭合网格及有效OBJ导出，以及平面投影与当前字形一致且不修改三维数据。笔顺测试逐字核对66笔数量、关键收笔和点画的归属，并检查实际渲染的天字中未来笔画不会提前出现。
