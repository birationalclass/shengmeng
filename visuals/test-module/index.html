BEHIND THE METAPHOR

诗意之外，定义之内。

这是一部以数学组织文明史的视觉寓言。“运算生成万象”是叙事主题，不是万物都构成群的断言。三个场景分别展示连接、作用与复合；可逆的变换才自然通向群。

01 / SEMIGROUP

文字的诞生 · 半群

设 Σ 是字符集合，所有非空有限字符串构成 Σ⁺。连接 u、v 得到 uv；结果仍是非空字符串，且 (uv)w 与 u(vw) 都按原次序列出三个字符串的全部字符，因此连接满足结合律，(Σ⁺, ·) 是自由半群。加入空串 ε，得到自由幺半群 Σ*。

(山 · 川) · 日 = 山 · (川 · 日)
(W · O) · RD = W · (O · RD)

非空字符串没有连接逆元：长度相加，无法连接出空串。所以这是半群／幺半群，不是群。图中文字连接只是形式结构；语法正确与语义成立还需要额外规则。

历史镜头：晚商甲骨文字与后来英语采用的拉丁字母分属不同的书写传统，不是同一文字的前后阶段。本片用现代“山、川、日”等字和拉丁字母作视觉转译，并非出土字形或印刷技术的年代复原。英语书写中的拉丁字母约于公元 600 年后传入，不能把更早的拉丁字母起源称作“英语诞生”。

02 / ACTION

牛顿的树与苹果 · 作用

落体受力与数学中的群作用不是同一个定义。两者的连接在于：运动法则给出相空间上的时间演化。以恒定重力、无阻力且不含地面碰撞的理想模型为例：

Φₜ(y,v) = (y + vt − ½gt², v − gt)
Φₛ ∘ Φₜ = Φₛ₊ₜ,　Φ₀ = id,　Φ₋ₜ = Φₜ⁻¹

代入可得位置项 y+v(s+t)−½g(s+t)²，速度项 v−g(s+t)，从而证得复合公式。因此加法群 (ℝ,+) 作用在相空间 ℝ² 上；只取非负时间则得到半群作用。画面在苹果触及底座后停下是叙事处理，不包含在这个可逆模型中。

历史镜头：1666 年的伍尔索普故事与 1687 年《自然哲学的数学原理》。苹果轶事来自后来记录的回忆，本片不描绘“苹果砸头”这一夸张版本，也不把万有引力的建立归结为某一个瞬间。

03 / COMPOSITION

人工智能 · 复合

一层网络可写成 fᵢ(x)=σᵢ(Wᵢx+bᵢ)，多层网络便是 F=fₗ∘···∘f₁。只要定义域与陪域匹配，复合满足结合律：((f∘g)∘h)(x)=f(g(h(x)))=(f∘(g∘h))(x)。相同空间上的自映射在复合下构成幺半群；不同维度的层则是可依次复合的映射。

x → f₁(x) → f₂(f₁(x)) → ··· → F(x)

激活、降维与概率采样一般不可逆，普通神经网络并不自动构成群。图中的齿轮、连接和光点是计算流程的艺术示意，不是完整 Transformer 架构，也没有在后台调用或训练 AI 模型。

历史镜头从 1956 年人工智能研究的学科奠基节点，走向 2017 年 Transformer 与当代生成模型；这不是把三个时间点当作技术发展的全部历史。

CODA / GROUP

群，在可逆的对称中出现。

设 X 为集合，可逆自映射的复合仍可逆；恒等映射为单位元，逆函数为逆元，函数复合满足结合律，因此全体双射构成群 Sym(X)。群作用正是把群元素解释为 X 上相容的可逆变换。这是影片从“生成的运算”回望群论的精确落点。
