# 形式化网页约定

- 每个形式化模块只对应一个最终定理；可以有必要的定义、辅助引理和编号分条的结论。
- 在 2D / 3D 图谱画布内，在所有证明步骤卡片上方展示模块的最终定理卡片；它是随视图缩放与移动的独立卡片，不是页面顶部栏，使用标准数学表述，完整写出假设与结论，并提供中英文版本。2D 与 3D 视角共用同一张最终定理卡片。
- 顶层定理卡片的完成状态单独核实。辅助步骤通过、条件式证明通过或网页加载成功，都不能将尚未完成的最终几何定理标记为已验证。
- 当前 negativity 模块的最终目标是原稿 Theorem 1.4（Proper negativity lemma）；两条结论属于同一个最终定理。现有图谱中的射影版本和其他节点是证明它的步骤或输入。

- 卡片严格参考用户提供的 MSMath 浅色界面：浅青到淡粉的背景、通透白色卡片、圆角和柔和阴影，不设硬边框，不对文字或卡片施加强模糊。数学标题和正文使用衬线字体，导航与状态使用系统无衬线字体。选中卡片使用蓝色标签、浅色浮起材质及内部流动柔光，不用静态黄色选中框；琥珀标签只表达未验证输入。已验证且选中的节点使用蓝色渐变流光边缘、冷银蓝金属玻璃面板，与接口和连线的金属质感呼应；未验证的选中节点保留较轻的银蓝流光。尊重减少动态效果的系统偏好。

- MSMath 对照参数取自其 SwiftUI / MathJax 源码：背景 RGB 为 (0.52, 0.83, 0.94)、(0.92, 0.90, 0.96)、(0.93, 0.69, 0.87)；圆角 16；普通卡片阴影半径 9、偏移 4、透明度 0.09，选中卡片半径 16、偏移 7、透明度 0.16。数学字体优先 New York / Times New Roman，控件优先苹果系统字体 / SF Pro Text，Windows 使用系统回退。
- 最终定理的编号结论上下顺排，不分栏。
- 未选中的已验证节点使用淡蓝色金属玻璃背景，选中时使用更亮的蓝色渐变流光；绿色状态胶囊和勾选徽章保留；条件式证明为蓝绿半圆状态，开放输入为琥珀问号与标签（不用菱形），最终未完成目标为空心灰色状态。状态来自数据，不由选中、动画或依赖节点颜色推断。
- 已验证卡片只显示勾选徽章，不重复显示 Verified by Lean 文案；详情、图例与无障碍标签保留完整验证状态。顶部导航和控件采用与卡片一致的圆角透光材质。

- 卡片输入输出接口为贴住边缘的向外半圆金属接口，连线连接圆弧最外端；连线使用冷银蓝色暗部、金属主体与细高光，保留原来的虚线假设语义，不增加证明依赖。
- 2D 选中新卡片时保持缩放，自动平移至适合阅读的位置：有前提的结论位于画布偏右，留出左侧依赖空间；基础输入靠中间。展开或折叠基础输入纸牌时，保持缩放及当前卡片的屏幕位置。只有明确的取景／缩放控件或用户滚轮手势才改变缩放；选择卡片本身不改变缩放。

- negativity 的证明世界将所有卡片按原稿证明模块归档；H / E / M 来源包与普通卡牌同在画布内，不设底部参考包架。每个数学证明界面恰有一个金色主定理卡（参考卡包除外）；金色仅标识主目标，验证状态仍来自 Lean 审计数据，普通卡片保留现有样式。
- negativity 的 Proof Atlas、Original proof、Verification evidence 与 2D、取景、缩放等控件统一放到底部小图标栏，保留双语无障碍名称和悬停提示。主页采用可交互图标，不显示 Home 文字。

- negativity 取消放大入场动画；数学证明界面的紧凑金色目标放在右侧，左侧按 PDF 原稿证明脉络展示相关卡片，外围卡片宽高上限为 280×156 CSS 像素。完整条件结论按需展开，参考来源与证明依赖区分。此规则替代目标上方或居中环绕布局。
- H / E / M 依赖卡包不适用唯一主定理规则；进入后不显示金色目标，卡牌从上到下重叠展开，每张至少完整露出标题；悬停或聚焦不改变叠放位置，左击整体平移画布使所选卡片居中偏右，并打开右侧信息，所有卡片相对位置不变。
- negativity 顶部标题右侧以绿色显示去重后的 Lean 源码总行数，底部不显示 3D 图标。

- 卡牌接口仅对应当前实际连线：无连接卡牌不显示接口，仅显示有连线的方向。纵向参考卡包无连线也无接口。

- 卡片标题下的中文说明（尤其参考来源、包内构造）使用与 PDF 证明脉络小标题相同的系统无衬线字体；数学公式保留数学字体，卡牌材质与标题设计保持。

- 删除卡片上的“进入模块”与“打开卡包”按钮；左击仅整体平移画布，使当前卡片位于适度偏右的居中阅读位置；全部卡片与连线一起移动，保持相对位置，不单独移动卡片，并在右侧面板显示该卡片／卡包信息，不缩放、不进入模块、不切换连接图；右击才进入模块或参考包，键盘用 Shift+F10 / ContextMenu。

- 卡片外不显示“编号＋阶段说明”（如“1. 射影归约 · nef 拉回”），仅保留卡片自身的数学标题；按原稿排列，不添加重复的小标签。

- 右侧信息面板的滚动区域严格限制在底部工具栏上方，并预留底部间距；绝对定位后不得沿用 height:100% 导致内容与工具栏重叠。

- 证明世界与参考卡包保留拖拽平移和鼠标滚轮缩放；拖拽卡牌或空白处整体移动画布，拖拽结束不误触点击，滚轮以鼠标位置为中心缩放，底部比例同步实际缩放，右侧面板滚动独立。

- 每张普通卡牌、金色目标与参考包成员显示 Lean 源码行数；重叠纸牌在露出的标题区域保留行数。参考包封面按包内卡片关联的源码文件去重汇总。切换模块／语言后及时更新；提示说明统计物理源码模块行（含注释、空行），不是单条证明的长度，缺少元数据不等于未验证。

- 数学证明世界按当前卡片数量与可用画布大小自适应行列；横向、纵向及金色目标间距都有合理上下限，小窗口收紧，少卡片不以空白网格撑满窗口。外围卡片仍不超过 280×156，窗口调整不修改用户缩放，布局后同步重绘连线；参考卡包保留纵向叠牌。


## 卡包封装与概览显示

- 顶层按数学证明的主要归约、构造、分类和矛盾展示证明主线，不机械地只展示最终 Lean 声明的直接依赖。证明确有多个实质阶段时，默认概览应直接展示这些阶段，不能把全部证明压进一个封面；真实的一步证明不强行凑卡片。
- 至少包含两个实质子步骤的完整子论证才显示堆叠卡包。单个定理、叶节点、等价桥接和简单转述显示普通卡片。真实的一前提论证可以进入“目标＋实际前提”的证明界面，但不伪装成卡包。叶节点右击或 Shift+F10 查看信息，不进入空证明世界。
- 概览成员和显示角色与 Lean 的实际依赖分开保存。概览可省略转述包装层；完整声明、精确条件、源码和连接图仍可访问。概览连线明确表示证明阅读路径，不把压缩后的关系宣称为直接 Lean 依赖。
- 普通卡统计自身声明与证明区间；真实卡包才统计去重后的实际项目依赖。中英文紧凑条件与结论均应适合卡片尺寸，展开详情保留完整数学条件。发布前检查默认桌面概览和手机分页，不仅检查全部卡片目录。
