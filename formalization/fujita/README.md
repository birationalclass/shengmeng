# Fujita freeness module

Independent manuscript and source-discovery module. The paper states global generation of K_X+(n+1)L for a smooth connected projective complex n-fold and an ample line bundle L. It does not claim the very-ampleness part here.

The matching Lean formalization has not been located in the checked official release. No source code, theorem proof, build success or axiom audit is fabricated. See audit.json and verification.txt for the precise checkpoint. The atlas nodes are a bilingual reading route through the manuscript, not kernel-verified proof dependencies.

Upstream paper and reference release metadata are redistributed under the upstream Apache-2.0 license. UI files follow the existing user project. Preserve separate audit and source status when importing a later formalization.
