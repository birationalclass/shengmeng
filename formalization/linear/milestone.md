# General closed-socle to relative-pairing bridge

The full Linearity Theorem remains unproved. This milestone advances the
general relative Jacobian argument, rather than extending a monomial example.

## Actual constructions and proofs

`Linear/SoclePairing.lean` proves that every nonzero ideal intersects the
annihilator of a nilpotent ideal nontrivially, using the least power that kills
the ideal. In a local Artinian ring this is its socle. For a finite-dimensional
commutative local algebra over a field, if that socle is generated by a nonzero
element as a vector space, a functional taking value one on the generator is
chosen by mathlib duality. Its multiplication pairing is proved injective,
then upgraded to an actual linear equivalence by equal finite dimensions.

`Linear/ResiduePairing.lean` uses the actual closed fiber

    C = (B / maximalIdeal B) tensor[B] A.

A closed-fiber functional is lifted with a finite free basis. The multiplication
Gram matrix is proved compatible with base change, and its closed-fiber
determinant is a unit because the constructed pairing is perfect. Local-ring
unit detection then gives an actual perfect pairing over B. Finite flatness
supplies the basis through `Module.free_of_flat_of_isLocalRing`; no free-basis
assumption remains in `exists_finiteFlat_pairing_of_residue_socle`.

`finiteFlat_annihilator_from_closed_socle` connects this construction to the
previous primitive-generator proof. Its inputs are explicit: delta annihilates
the reduction kernel, its tensor-product closed-fiber image is nonzero, and that
image scalar-generates the closed-fiber socle. It concludes that the reduction
kernel's annihilator consists precisely of scalar multiples of delta. It does
not assume a perfect-pairing object or an invertible Gram determinant.

## Remaining mathematical obligations

For the actual multivariable relative Jacobian delta, still prove:

1. Generic-fiber Scheja--Storch annihilation and its flat descent.
2. Closed-fiber complete-intersection socle generation and nonvanishing.
3. The change-of-parameter-ring construction needed for arbitrary lifts.

The new bridge then handles pairing existence and the primitive coefficient
argument. Bertini, the global residue relation, proper duality/Koszul/Serre
geometry, scheme comparison and the actual intersection bound remain open.

## Library-first discovery, 2026-10-06

Online searches covered Scheja--Storch/Jacobian/socle Lean implementations,
Gorenstein local rings and complete-intersection libraries. Exact original PR
metadata and source files were inspected, not just similarly named results.

- mathlib PR 34913, head c7780ed427bbed31ee0c430a5594ed5ea4c7d5b5,
  remains open. Its complete-intersection file supplies definitions, epsilon
  invariants and Koszul-based results; it does not provide the required
  multivariable Jacobian/socle theorem. It imports a substantial additional
  depth/CM/Koszul stack, absent from the pinned environment. No wholesale
  toolchain upgrade or unexamined PR import was made.
- mathlib PR 31884, live head f1b91f73edba51d6d27523b3ebafa1dcf023f0a3,
  remains open. Its inspected Gorenstein file defines finite self-injective
  dimension and proves equivalence/localization-interface facts. It does not
  prove the socle theorem needed here. An older external index listed a
  different head; the live GitHub API was used to resolve that drift.
- Reused pinned mathlib code: Artinian nilpotence, finite-dimensional duality,
  equal-rank injective maps, actual tensor-product bases and dual base change,
  local finite-flat freeness, quotient/tensor comparison, matrix determinants.
