# Milestone 64: actual cone function-field map

The original Linearity Theorem remains unproved. This checkpoint constructs and
checks the actual homogeneous-coordinate map and its induced fraction-field map.

1. Positive-degree projective surjectivity lifts to the affine cone over the
   complex field, using roots. Total invariance gives surjectivity on the cone
   of the original integral projective equations.
2. Cone surjectivity and the Nullstellensatz give equality of the contracted
   homogeneous prime ideal. Consequently the actual quotient-ring map is
   injective; injectivity is not supplied as an additional assumption.
3. The same original hypotheses give a smooth source point where the first
   homogeneous coordinate pullback is nonzero, on an inhabited standard chart.
4. The induced map on the actual fraction field is constructed with its exact
   algebra-map compatibility. Finite transcendence degree makes the extension
   over its actual image algebraic. Essential finite type makes it finite, and
   characteristic zero makes it separable and formally unramified. These image
   extension properties are transported to the actual map itself.

Scope: the fraction field here is that of the homogeneous coordinate domain,
the function field of the affine cone. It is not yet the degree-zero projective
function field. Neither the extension degree nor an entire general smooth
unramified projective fiber has been constructed.
