# Milestone 22: actual syzygies and affine ideal degree control

The full Linearity Theorem remains **UNPROVED**. The manuscript is unchanged.

`FirstSyzygy.lean` derives a first relation of a regular sequence as a boundary in the actual Koszul complex. Exterior-power generation converts that boundary to an explicit skew matrix: `a_i = sum_j c_ij H_j`, `c_ij = -c_ji`, `c_ii = 0`. For homogeneous equations, the coefficient matrix has the required weighted homogeneous degrees and vanishes when the degree would be negative. No syzygy-generation input is assumed.

`FilteredIdeal.lean` uses these actual syzygies to remove highest-degree cancellations in an affine ideal representation. With regular highest homogeneous parts, every element `f` of the affine equation ideal has a representation `f = sum_i a_i P_i` with each nonzero summand satisfying `deg(a_i)+deg(P_i) <= deg(f)`. Thus, for `deg(f) <= N`, its degree-N homogeneous component belongs to the ideal generated by the highest parts. This is an actual filtered ideal comparison, proved by degree induction.

The proof of skew cancellation works in arbitrary characteristic; it does not divide by 2. The affine filtered lemmas require a field and explicit regularity of the highest parts. They do not yet derive that regularity from a geometric no-infinity condition.

Library discovery used the official mathlib regular-sequence and ShortComplex/ModuleCat APIs, together with the already licensed and audited Koszul complex port recorded in `vendor-provenance.json`. The missing bridge is the explicit skew homogeneous representation and degree-lowering argument, implemented here. Pinned mathlib: `2a885768dae569d938bb9ff3474da6a8753bb90a`, Lean 4.35.0-rc3.

This filtered ideal comparison is not itself the global residue theorem. The next step is to construct a low-degree vanishing functional on the actual affine quotient and identify its normalization against the actual universal difference diagonal. Geometric charts, global compatibility, Serre/duality and intersection estimates remain open. Local build/axiom evidence and GitHub deployment evidence are separate.
