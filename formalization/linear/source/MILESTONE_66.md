# Milestone 66: actual projective chart function field

The full Linearity Theorem remains unproved.

Starting with the original positive-degree surjective homogeneous projective
map and a totally invariant integral projective zero set, the actual cone
fraction-field map now restricts to the field generated by coordinate ratios.
Stability is derived from the homogeneous coordinate formulas of that map.
The restricted field map is finite and formally unramified in characteristic
zero. These properties are proved rather than added as hypotheses.

For an inhabited standard chart, the coordinate-ratio polynomial map has kernel
exactly the dehomogenized homogeneous ideal. This follows from the actual
localization kernel and the proved contraction identity for homogeneous ideals.
The resulting actual chart coordinate domain embeds into the cone fraction
field. Its fraction field has image exactly the coordinate-ratio field, giving
an explicit algebra equivalence between the two fields.

The standard chart is explicitly assumed inhabited; its selection from an
arbitrary projective variety remains a separate coordinate-choice obligation.
The field-extension degree has not been identified with q^dim(V). A general
nonramified projective fiber with the requisite cardinality, the geometric
dimension comparison, uniform global duality lifting and geometric Bezout
remain unfinished. In particular, a generically unramified field map alone
does not yet prove the main theorem's required whole-fiber statement.
