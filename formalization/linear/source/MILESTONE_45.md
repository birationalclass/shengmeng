# Milestone 45: actual target-local pullback generation

For arbitrary actual ring maps, a point-local ideal presentation transfers when the actual localization denominators are units. The extension through the actual localization is constructed, rather than assumed.

For the polynomial smooth formal map constructed in milestone 44, invertibility is equivalent to nonzero evaluation at the actual source point. Consequently, pulling back a point-local presentation at the image point gives precisely the ideal generated by the formal images of the pulled-back polynomial equations. No globally complete-intersection ideal presentation is required.

The source and target point-local smooth presentations are still explicit geometric inputs. This closes the target ideal-generation comparison and removes the need to assume an opaque extension homomorphism. The exact global Linearity Theorem is still unproved.

Reuses mathlib Localization lift, lift_comp and lift_eq, actual polynomial eval_assoc, the constructed formal smooth automorphism and point constant-coefficient comparison. No new axiom.
