原 Hom 上的源环作用The source algebra acts on the original Hom

f:X→Y 是概形态射，N 是 𝒪Y 模层，U⊂Y 是开集。

Let f:X→Y be a scheme morphism, N an 𝒪Y-module sheaf, and U⊂Y an open.

BU = Γ(f−1U,𝒪X),
HU = Hom𝒪U((f*𝒪X)|U, N|U).

(b·h)W(x) = hW(b|f−1W · x),   W⊂U.

HU is a BU-module. The action preserves the original restrictions and agrees with the original 𝒪Y action on pulled-back base functions. These compatibilities are proved.

实际导出对偶的零次同调Degree-zero homology of the actual derived dual

[−] 设[−] Let

φ:A→B 是交换环同态，I 是 A 的内射分解，G = coextendScalars(φ)。

Let φ:A→B be a commutative-ring map, I an injective resolution of A, and G = coextendScalars(φ).

⇒ 则⇒ Then
H⁰(G(I)) ≅ HomA(B,A)   （B 模同构）(as B-modules).

各项 G(Iʲ) 是 B-内射模；不同内射分解给出同伦等价复形。在原整射影模型的有限、单射、齐次线性投影下，此 H⁰ 还可 B-线性嵌入 B。这里尚未识别 ωV，也未完成全局的正扭曲嵌入。

Every G(Iʲ) is B-injective, and different injective resolutions give homotopy-equivalent complexes. For the original integral projective model with a finite injective homogeneous linear projection, this H⁰ also embeds B-linearly into B. Identification with ωV and the global positive-twist embedding remain open.
