任意开集上的源环线性Source linearity on every open

仿射拟凝聚层的原映射，在整体截面上保持源环乘法，就在每个开集上保持每个局部源函数的乘法。原 Lemma 4.1 仍未完成。

An original affine module-sheaf map that preserves source multiplication on global sections preserves multiplication by every local source function on every open. Original Lemma 4.1 remains open.

已证：整体截面 ⇒ 任意局部截面Proved: global sections ⇒ every local section

Y = Spec R,  α : OY → S,
M, N : S-module sheaves,
M and S quasicoherent over OY,
C : M↓α → N↓α,  C OY-linear,
∀ b ∈ Γ(Y,S), ∀ x ∈ Γ(Y,M),
CY(b·x) = b·CY(x).

源环作用相互交换；交换源环时自动满足。目标 N 不要求拟凝聚，也不要求限制映射满射。

The source scalar actions commute; this holds for a commutative source ring. No target quasicoherence or surjective restriction is required.

Affine-QC faithfulness first handles global source functions. Comparing actual Hom sections b ↦ b·x then proves the formula for all local source functions.
